# Security Policy

## Supported versions

Security fixes are released against the latest version on the VS Code Marketplace and Open VSX.

## Reporting a vulnerability

Do not open public issues for security problems.

Report privately through GitHub's "Report a vulnerability" button on the
[Security tab](https://github.com/pingaura-ai/pingaura-vscode/security/advisories/new),
or email security@pingaura.ai.

Where possible, include the extension and VS Code versions, a description of the issue and its impact, and steps to reproduce.

We acknowledge reports within 3 business days. For confirmed issues we ship a fix or mitigation prioritized by severity and keep you updated.
